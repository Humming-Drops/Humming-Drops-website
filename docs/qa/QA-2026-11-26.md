## Before deploying

1. Set a private `SESSION_SECRET` (32+ characters). Without it nobody can sign in. Everyone signed in before the release must sign in again.
2. Run `npm run db:migrate` against the production database (`0009`, `0010`). The app still runs without them, but sign-out will not revoke copied cookies.
3. Set `NEXT_PUBLIC_APP_URL`, `RESEND_API_KEY` and `MAIL_FROM`. Without a mail provider, password reset reports success but sends nothing.
4. If online payments are ever enabled, set `CHECKOUT_MODE`.
